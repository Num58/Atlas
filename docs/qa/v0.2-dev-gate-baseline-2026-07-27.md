## 4. 零网络门禁（V0.2 必须为 0）

### 必须提供的三类证据

1. **静态零业务网络能力**：业务代码不得直接 import `dart:io` 网络类、`package:http`、Dio、gRPC、WebSocket，也不得使用网络图片/资源构造器；依赖树须保留审计结果。
2. **ThrowOnCall**：`CloudSyncPort`、`RemoteAssistedDiscoveryPort`、`AuthPort`、`HealthPort`、`CalendarPort`、`LocationPort`、`ContentPort` 注入测试适配器；任一调用立即抛 `UnexpectedExternalCall` 并记录 adapter/method。
3. **真实闭环 E2E**：断网运行新游客→方向→显式确认→域→目标/里程碑→旅程/我的→重启；应用业务 HAR 请求为 0，全部 ThrowOnCall 计数为 0。工具链下载源或系统流量不得冒充业务零网络证据。

### 当前静态观察

- `lib/**/*.dart` 未发现 `dart:io` 网络类、`package:http`、Dio、gRPC、WebSocket、网络图片构造器或显式 HTTP URL 命中。
